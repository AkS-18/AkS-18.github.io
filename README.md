## About

This portfolio was built as part of a practical software engineering activity sequence (Activities 1–5). It documents my hands-on work with developer tooling, version control, collaborative coding, and algorithmic problem solving — and presents it through a clean, single-page portfolio.

The focus of the activity was on **briefing, directing, and refining AI-generated output** to produce a polished, professional result — rather than writing code from scratch.

## Tech Stack

- **HTML5** — single-file, no build step required for deployment
- **Vanilla CSS** — custom design system with CSS variables, animations, and responsive layout
- **Vanilla JavaScript** — navbar scroll, mobile menu, project category filtering
- **Google Fonts** — Bricolage Grotesque (hero), Plus Jakarta Sans (wordmark), Inter (body), JetBrains Mono (code)

> The `portfolio/` subdirectory contains an earlier React + Vite prototype. The live portfolio is the standalone `index.html` at the root of this repository.

---

## Running Locally

No build step needed. Simply open the root `index.html` in your browser:

```bash
# Option 1 — open directly
start index.html          # Windows
open index.html           # macOS

# Option 2 — serve with any static server
npx serve .
```
